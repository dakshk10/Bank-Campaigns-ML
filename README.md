# Bank Campaigns ML — Smarter Bank Campaigns

DJS Compute AIML Mentee Assignment. Predicts which historical bank
clients were likely to subscribe to a term deposit (Task 1, supervised
learning), and explores whether meaningful client segments exist
(Task 2, clustering), using the UCI Bank Marketing dataset.

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Download the dataset — see `data/README.md` for the link and where
   to place it.
3. Open the notebooks in order:
   - `01_data_audit.ipynb` — data audit and feature availability
   - `02_supervised_learning.ipynb` — Task 1: supervised learning
   - `03_clustering.ipynb` — Task 2: clustering
4. Run each notebook top to bottom (Restart → Run All).

## Reproducibility

- The dataset is date-ordered; a fixed, non-random 80/20 split is used
  to create a temporal holdout, so results are reproducible across
  runs.
- `random_state=42` is set wherever models or sampling involve
  randomness.
- Decisions behind preprocessing, model choice, and evaluation metrics
  are documented in `decision_justifications.md`.

## Deliverables

- `01_data_audit.ipynb`, `02_supervised_learning.ipynb`,
  `03_clustering.ipynb` — the three notebooks
- `decision_justifications.md` — reasoning behind each major decision
- `top_500_holdout.csv` — ranked top-500 holdout table (generated by
  `02_supervised_learning.ipynb`)
- Decision memo (up to 2 pages) — final 500-call recommendation
