# Dataset

This project uses `bank-additional-full.csv` from the UCI Bank Marketing
dataset.

Download it from: https://archive.ics.uci.edu/dataset/222/bank

After downloading, place `bank-additional-full.csv` directly in this
`data/` folder before running the notebooks.

This is what lets someone clone this repo and reproduce the work — they
download the data themselves rather than it being re-distributed here.
